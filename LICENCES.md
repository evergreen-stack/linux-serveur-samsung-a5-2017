# Licences et composants

Les fichiers d'origine conservent leurs droits et licences ; le nom du projet ne remplace pas ceux de postmarketOS, Nura, Alpine Linux, LineageOS ou Team Win.

- Sources et scripts originaux du tableau, des menus et du packaging de ce projet : MIT, voir `LICENSE`.
- APKBUILD/deviceinfo du port : licence indiquée dans le paquet `device-samsung-a5y17lte` (MIT).
- Noyau Linux et patches dérivés : GPL-2.0-only, conformément à l'APKBUILD. Le tarball exact, la configuration et tous les patches du paquet sont fournis.
- Recovery installer postmarketOS : GPL-3.0-or-later, en-têtes conservés et archive source 1.0.7 fournie.
- qcacld et firmwares : licences upstream, décrites dans leurs sources et métadonnées de paquet. Les firmwares sont ceux déjà fournis par le port, pas des créations de ce projet.
- APK officiels : signatures et métadonnées conservées ; `release/paquets-installes.txt` décrit les versions dans la ROM.
- Police Terminus : incluse par le paquet de la distribution et utilisée pour les rendus ; licence upstream conservée dans la distribution.
- TWRP 3.7.0_9-0 : image officielle Team Win pour a5y17lte. Page originale : https://dl.twrp.me/a5y17lte/twrp-3.7.0_9-0-a5y17lte.img.html . Pour une publication web, le dépôt fournit un lien vers cette page ; les binaires ne sont pas suivis par Git.
